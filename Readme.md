# 💈 JEAN DO CORTE BARBER

> Site profissional e responsivo para uma barbearia, desenvolvido com HTML5, CSS3 e JavaScript.

---

## ✂️ Sobre o projeto

O **Jean Do Corte Barber** é um projeto de website desenvolvido para apresentar os serviços de uma barbearia de forma moderna, elegante e profissional.

A página foi criada com uma identidade visual baseada principalmente em **preto, dourado e branco**, buscando transmitir uma experiência sofisticada.

O site reúne informações sobre a barbearia, serviços, profissional, galeria, avaliações, agendamento, formas de pagamento, localização e contato.

A seção inicial apresenta:

* Nome da barbearia
* Slogan
* Apresentação do serviço
* Avaliação visual
* Botão para agendamento
* Botão para visualizar os serviços

Seção destinada à apresentação do profissional e da proposta da barbearia.

---

### 💈 Serviços

O site apresenta quatro serviços:

| Serviço         |    Preço |
| --------------- | -------: |
| Corte Masculino | R$ 35,00 |
| Corte + Barba   | R$ 55,00 |
| Barba           | R$ 25,00 |
| Corte Infantil  | R$ 30,00 |

O serviço **Corte + Barba** possui destaque como serviço mais procurado.

---

### 👨‍💼 Jean Do Corte Barber

Seção dedicada ao profissional responsável pelos atendimentos.

Apresenta:

* Foto do barbeiro

* Informações sobre o atendimento
* Botão para agendamento

A galeria apresenta imagens relacionadas ao trabalho da barbearia.

Recursos previstos no projeto:

### 🔍 Lightbox

O projeto possui uma estrutura de **Lightbox** para visualizar as imagens da galeria em tamanho ampliado.

Também existe um botão para fechar a imagem ampliada.

### ⭐ Depoimentos

## 📅 Agendamento

O site possui um formulário de agendamento.

O cliente pode informar:

* Nome
* Telefone
* Serviço
* Barbeiro
* Data
* Horário
* Forma de pagamento

### Serviços disponíveis

* Corte Masculino
* Corte + Barba
* Barba
* Corte Infantil

### Horários disponíveis

O formulário possui horários entre **09:00 e 18:00**, com intervalos de 30 minutos e pausa no período do almoço.

---

## 💳 Formas de pagamento

O formulário permite selecionar:

* Pix
* Cartão
* Pagamento na barbearia

Também existe uma seção específica para pagamento via **Pix**.

> ⚠️ A chave Pix exibida no código está como `SUA_CHAVE_PIX` e deve ser substituída pela chave real antes da utilização do site.

---

## 📱 WhatsApp

O projeto possui integração visual com o WhatsApp.

O botão permite que o cliente entre em contato para solicitar um agendamento.

Também existe um botão de WhatsApp dentro do modal de confirmação do agendamento.

> ⚠️ O número utilizado no código é um número de exemplo e deve ser substituído pelo número real da barbearia.
